# Buzz Challenge — 프랑스어 학습 도전 기록

Buzzvil 사내 챌린지에 분기별로 참여한 기록. 각 분기 폴더에 도전 과제·인증 방법·월별 결과가 정리돼 있다.

| **2026 Q4** (10\~12월) | 말하기 | Focus (1개월) | 매달 ChatGPT 프랑스어 회화 **30세션 이상** (유연 조정) | ⬜ | — |

## 챌린지 방식
- **Focus Challenge**: 매달 달성 여부를 인증하는 단기집중형.
- 동일/유사 주제로 이어갈 경우 **이전 분기보다 높은 목표**를 설정한다 (규정).
  - Q2(문법) → Q3(작문)은 **영역 자체가 다름**(신규 주제)이라 상향 규정 비해당.

## 인증 원칙
모든 인증은 **이 GitHub 저장소의 파일 링크**로 검증 가능하게 한다.
- Q2: 해당 월 **월말누적평가** 채점 결과 파일 ([`grammar/tests/`](../grammar/tests/)).
- Q3: 해당 월 **누적 단어수·달성 여부** 기록 파일 (작문 원문은 [`writing/exercises/`](../writing/exercises/)에 보관).
- Q4: 해당 월 **회화 세션 수·달성 여부** 기록 파일 (ChatGPT 대화 JSON export 보관 — timestamp·turn으로 검증. 시간 미측정, **세션 수** 지표. transcript 신뢰도와 무관). 내부 학습용 = 세션별 짧은 회고(주제·막힌 표현·새 표현).
  - **목표는 달의 일수와 무관하게 매달 30세션 고정** (문장을 단순하게 유지).
  - **하루 1세션이 상한이 아니다** — 하루에 여러 번 해도 각각 1세션으로 센다. 못 한 날은 다른 날 몰아서 만회 가능.
  - **세션 경계 = 대화방(conversation) 1개** (사용자 결정, 9/10). 매 세션 새 대화방을 만든다. 같은 방에서 이어 말한 것은 세션을 늘리지 않는다.
