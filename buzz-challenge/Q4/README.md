## 세션 산정 기준
- **세션 = ChatGPT 대화방 1개**. 세션마다 새 대화방을 만든다. 같은 대화방에서 음성을 여러 번 열어도 1세션이다.
- 하루 1세션이 상한이 아니다. 하루에 여러 번 해도 각각 1세션으로 센다.
- 목표는 달의 일수와 무관하게 매달 30세션.
- 시간은 재지 않는다. 대화방의 생성 시각·발화 기록으로 확인할 수 있다.
