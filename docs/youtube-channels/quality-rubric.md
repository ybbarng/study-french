# 영상 내용 품질 기준 (2026-11-08 사용자 요청)

영상마다 아래 6항목을 1~5점으로 매기고, 점수마다 근거 한 줄(가능하면 시간 위치)을 적는다. 채널은 영상 점수의 평균과 편차를 낸다.

| 항목 | 묻는 것 | 5점 | 1점 |
|---|---|---|---|
| ① 정확성 | 문법 설명·프랑스어 예문·발음 설명이 맞는가 | 틀린 곳 없음 | 핵심 설명이 틀림 |
| ② 실제 쓰임 | 원어민이 실제로 그렇게 말하는가, 구어/문어·격식 구분을 밝히는가 | 쓰임과 말투를 정확히 구분 | 교과서식·번역투, 실제와 어긋남 |
| ③ 설명의 명료성 | 왜 그런지(규칙·뉘앙스)를 이해하게 하는가 | 원리와 반례까지 | 외우라고만 함, 헷갈리게 함 |
| ④ 학습 밀도 | 영상 길이 대비 배울 것의 양 | 1분마다 쓸 거리 | 잡담·광고가 대부분 |
| ⑤ 프랑스어 노출 | 원어민 프랑스어를 실제로 듣는 비율과 질 | 자연스러운 원어민 발화가 많음 | 프랑스어가 거의 없음 |
| ⑥ Brice 적합도 | 지금 Brice(말하기·듣기 A2, 문법 B2)에게 새롭고 쓸모 있는가 | 바로 말하기·듣기에 쓸 수 있음 | 이미 앎 또는 수준이 안 맞음 |

- 종합 = ①을 두 배로 셈한 평균 (정확성이 가장 중요). ①이 2점 이하면 종합과 상관없이 "자료로 쓰지 않음".
- 틀린 곳은 "원문(짧게) → 바른 설명 → 근거"로 적는다. 근거는 문법 자료(/Users/ybbarng/personal/projects/study-french/grammar/materials/)나 일반적인 프랑스어 규범.
- 확신이 없는 지적은 "확인 필요"로 따로 둔다. 점수를 부풀리거나 깎지 말고 근거로만 매긴다.
