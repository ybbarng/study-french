## 진행 방식

1. ChatGPT French Speaking 프로젝트에서 **세션마다 새 대화방** (이름은 001, 002 … 숫자. 버즈챌린지 인증에 대화방 목록 사용)
2. 첫 메시지 = 지난 FR-PROGRESS 줄 + `Session N` → 텍스트 카드
3. 음성 수업 → 채팅에 `세션 종료` → FR-PROGRESS
4. 사용자가 Claude Code에 "정리해 줘" → Claude가 Chrome으로 대화를 읽어 사본 저장, 아래 표·버즈 문서 갱신, 다음 대화방 첫 줄을 만들어 준다
