## 단서: 음성 모델과 텍스트 모델이 다르다

- 음성 발화의 `model_slug`는 `bidi`이고, 텍스트 답은 `gpt-5-6-instant`다. 텍스트 쪽은 한국어 전환·정리를 잘하고, 음성 쪽에서만 순서 이탈·언어 고정이 생긴다.
- 음성 모델도 한국어를 아예 못 하지는 않는다. Chat 004에서는 « 피드백. 잘한 점 : … »을 한국어로 말했고, Chat 005에서도 늦게나마 한국어로 답했다. **지침에 적힌 문장을 읽을 때는 한국어가 나오고, 스스로 언어를 바꿔야 할 때 잘 못 하는 것**으로 보인다.
- 그래서 v3는 ① 한국어를 지어내지 않고 지침·카드에 적힌 문장을 읽게 하고, ② 오늘 표현을 텍스트 모델이 카드로 먼저 대화에 올려 두게 했다. 음성 모델은 대화에 이미 있는 카드를 따라가기만 하면 된다.

## 원인 구별 실험 (지침 탓인가, 음성 모드의 한계인가)

같은 순서로 두 번 해 본다. **A = 프로젝트 밖의 새 음성 대화(지침 없음)**, **B = French Speaking 프로젝트 안의 새 음성 대화**.

1. 프랑스어로 3번 주고받는다 (예: « Bonjour, ça va ? » → 대답 → « Qu'est-ce que tu as fait aujourd'hui ? »).
2. 한국어로 « 이제 한국어로 말해 줘 »라고 한다.
3. 한국어로 아무 질문이나 한다 (« 오늘 날씨 어때? »).
4. « En coréen, s'il te plaît »라고 한다.

| 결과 | 해석 | 다음 조치 |
|---|---|---|
| A도 B도 프랑스어 유지 | 음성 모드 자체의 한계 | 한국어가 필요한 부분(뜻·번역·피드백)은 텍스트 카드·텍스트 정리로만 해결. 음성은 프랑스어 전용으로 설계 |
| A는 전환, B는 유지 | 지침 탓 | 지침에서 프랑스어 쪽으로 당기는 문장을 더 찾아 줄임 |
| 둘 다 전환 | v3 지침이 효과 있음 | 그대로 유지 |

결과는 이 파일에 적어 둔다.

## Chat 001 전체 흐름 (2026-10-15, 앞 페이지까지 받아서 분석)

음성 연결이 한 번 끊겼다(`voice_session_id` 두 개). 재연결 직후 메시지 1개(`8de8b900…`)는 export에 없다.

| 시점 | 실제로 일어난 일 | 문제 |
|---|---|---|
| 인사 | 「Bonjour Brice ! Ça va ?」 → 「Ça va, merci. On fait quelle session ?」 | 정상 |
| 세션 선택 | 사용자 « Je ne me rappelle pas »(기억 안 남) → 「D'accord, on discute librement.」 | "번호 없음" 규칙을 문자 그대로 적용해 자유 대화로 빠짐. 사용자가 « Session un »이라고 다시 말해서 돌아옴 |
| 연결 끊김 | 사용자 "그런가"(한국어 혼잣말) → 「Peux」에서 끊김 | 재연결 후 « Recommence »로 다시 시작 |
| 복습 | 「Comment tu dis en français : "plus lentement, s'il te plaît" ?」 → E02·E01·E03 연습 | **Session 1은 복습이 없어야 한다.** E01~03을 복습으로 쓰고 신규를 E04~06으로 밀었다(한 칸 밀림). 질문에 정답을 프랑스어로 넣어 버림 |
| 복습 중 | 사용자 « Répété, s'il vous plaît » → 「Presque. On dit : plus lentement…」 | 다시 말해 달라는 요청을 답안으로 채점함 |
| 복습 중 | « Plus lentement, s'il vous plaît » → 「Très bien.」 / « Répète, s'il vous plaît » → 「Très bien.」 | vous 오류를 어떤 때는 고치고 어떤 때는 넘어감 |
| 신규 1 (E04) | 표현 + **한국어 뜻** + 예문 + 따라 하기 + 문장 만들기 | 정상 (음성에서도 한국어가 나옴) |
| 신규 2 (E05) | 표현 + **한국어 뜻** + 예문 + 따라 하기 | ⑤ 자기 문장 만들기 건너뜀 |
| 신규 3 (E06) | 표현 + 예문(표현 그대로) + 따라 하기 | **한국어 뜻 빠짐**, ⑤ 건너뜀, 예문이 표현 자체 |
| 적용 | 「Comment on dit « train » en français ?」 → 사용자 « Train » | 목표 표현과 똑같은 질문을 던져서 사용자가 단어로만 답함 |
| 종료 | 사용자 « Je cherche le mot » → 「Parfait. On s'arrête là pour aujourd'hui.」 | 재연결 후 약 4분 만에 선생님이 스스로 끝냄. 자유 대화 없음. 피드백도 프랑스어 |

**정리**
- **한 칸 밀림**이 이후 세션에도 이어졌다. Chat 004(Session 2)가 E07~09를 한 것도 같은 원인으로 보인다. Session 0의 명령 연습(C1≈E01, C2=E02)이 E01~03을 이미 배운 것처럼 보이게 만든 것 같다.
- **언어 문제의 단서**: 같은 음성 세션 안에서 표현 1·2는 한국어 뜻을 말했고 3은 빠뜨렸다. 음성 모드에서 한국어가 막힌 게 아니라, **뒤로 갈수록 단계를 흘리는 것**에 가깝다.
- **v3.1 반영**: Session 1 = E01~03 신규라고 명시, 목표 표현과 같은 질문 금지, 다시 말해 달라는 요청은 채점하지 않고 먼저 따르기, 예문은 표현 그대로 쓰지 않기, 「Répète」와 E01 둘 다 정답, vous 교정은 항상 같은 방식.

## v4 (2026-10-15) — 대화 6개 전체 분석 반영

근거는 `chatgpt-transcripts/`와 `chatgpt-transcripts/voice-vs-text.md`. 바뀐 점:

- 말은 유치원 수준(1문장·8단어, 예/아니오 → 고르기 → 빈칸 → 자유), 대우와 주제는 성인
- 다시 말해 달라는 요청은 채점하지 않고 더 짧게 (같은 문장 반복 금지)
- 질문하고 스스로 답하기 금지, 「À toi」 대신 할 일을 구체적으로
- 음성 재연결 때 인사 없이 멈춘 단계부터, 다른 대화 기억으로 추측 금지
- 워밍업·자유 대화를 기본 단계에서 뺌 (워밍업 답을 기다리지 않고 넘어가는 일이 반복됨)
- 틀린 문장 칭찬 금지, 종료 신호에 「C'est assez」「그만」 추가
- Session 0 삭제 (Chat 003에서 완료)
- 음성에서 한국어로 안 바뀌면 채팅으로 적는 방법을 사용 방법에 적어 둠 (텍스트는 한국어가 확실함)
