# 음성 vs 텍스트 — 된 것 / 안 된 것 점검표

Chat 001~006 전체 사본에서 실제로 일어난 일만 모았다. 음성 = `bidi` 모델(🎙️), 텍스트 = `gpt-5-6`/`gpt-5-6-instant`(⌨️).

## 음성에서 된 것 ✅

| 한 일 | 근거 |
|---|---|
| 한국어 입력을 알아듣고 내용대로 따름 | 003 "먼저 표현을 알려주고 반복하게 해야지" → 따름 / 006 "세션 여기까지 하자" → 종료 |
| 문장 속 한국어 단어를 프랑스어로 알려 줌 | 002 « 음식 » → « la nourriture » / 004 « 충분하다 » → « suffire » |
| 복습 질문에 한국어 단서를 넣음 | 004 « comment on dit en français 천천히 ? », « 다시 말해줘 » / 005 « '다시 한 번' » |
| 단어 하나의 뜻을 한국어로 | 005 « indice » → « 힌트 » / 006 « long » → « 길 »(틀린 번역) |
| 신규 표현의 한국어 뜻 | 001 E04 « … 무슨 뜻이에요 ? », E05 « 프랑스어로 어떻게 말해요 ? » (E06은 빠짐) |
| 프랑스어 문장을 한국어로 번역 | 005 « On va reprendre plus simplement » → « 더 쉽게 다시 해보자 » |
| 종료 피드백을 한국어로 | 004 « 피드백. 잘한 점 : … 고칠 점 하나 : … » |
| **음성 세션 전체를 한국어로** | **005 음성 2: 한국어 텍스트 대화 직후 새 음성 세션 → 처음부터 끝까지 한국어** |
| 「Pardon」에 더 짧게 바꿔 말함 | 003 음성 1 (« plus court : tu dis quoi après « Ça va ? » »), 004 (« Un petit détail, qu'est-ce que tu as vu là-bas ? ») |

## 음성에서 안 된 것 ❌

| 안 된 일 | 근거 |
|---|---|
| **진행 중에 자기 말을 한국어로 바꾸기** | 005 음성 1: 한국어로 해 달라는 요청 8회+ → 모두 "한국어로 하겠다"고 **프랑스어로** 답함 / 003 음성 2: 한국어 항의 3회 → 프랑스어 / 006 음성 2: 한국어 메타 질문 5회 → 프랑스어 |
| 「En coréen」 뒤 한국어 유지 | 005: 한국어 한 구절 말하고 바로 « On revient en français ? » |
| 신규 표현마다 한국어 뜻 | 002·004·005·006 신규 표현 전부 프랑스어 설명뿐 (001만 3개 중 2개) |
| 세션 번호에 맞는 표현 | 001 S1→E04~06, 004 S2→E07~09, 006 S4→E07·E08·E13 |
| 단계 순서 지키기 | 자기 문장 만들기(⑤) 거의 매번 건너뜀, 적용 연습은 질문 1개, 워밍업 답을 기다리지 않음 |
| 먼저 끝내자고 하지 않기 | 001·002 스스로 종료, 003 음성 3 "끝낼까?" 반복 |
| 끝내자는 말 알아듣기 | 004 « Ça suffit pour aujourd'hui »를 발음 연습으로 바꿈 |
| 짧게 말하기 | 005 못 알아들을수록 설명이 길어짐 / 006 메타 답변 프랑스어 7문장 |
| 진도 기억 | 006 « vous savez quelle session ? » → « Je ne sais pas. » |
| 맞는 문장은 고치지 않기 | 004 « comment on dit » → « comment dire »로 교정 |
| FR-PROGRESS | 004 소리 내어 읽다가 잘림 |

## 텍스트에서 된 것 ✅ / 안 된 것 ❌

| | 한 일 | 근거 |
|---|---|---|
| ✅ | 한국어로 바로 답함 | 002·003·005 모든 텍스트 답 |
| ✅ | 진행 오류를 정확히 짚음 | 006 종료 정리 "E10~E12 대신 다른 표현… 미완료" / 005 세션 구성 설명 |
| ✅ | FR-PROGRESS 작성 | 001~006 |
| ❌ | 다른 대화의 기록을 정확히 요약 | 002: Session 1 FR-PROGRESS를 Chat 001 원래 기록과 다르게 다시 씀 |

| ❌ | 과장 없는 평가 | 003: "C1~C11 모두 완료"라고 했지만 상황 연습은 4개만 함 |

## 언어 전환 가설: 음성 세션을 시작할 때 직전 메시지의 언어를 따른다

| 음성 세션 시작 직전 메시지 | 음성 언어 | 근거 |
|---|---|---|
| 텍스트 답이 한국어로 끝남 ("지금 이 답변 자체를 한국어 음성으로 말할게.") | **한국어** | 005 음성 2 |
| 텍스트 답이 한국어 설명 + 프랑스어 「Bonjour Brice ! Ça va ?」로 끝남 | 프랑스어 | 003 음성 2 |
| 텍스트 「Bonjour Brice ! Ça va ?」 | 프랑스어 | 003 음성 1 |
| 직전 메시지 없음 (새 대화) | 프랑스어 | 001·002·004·006 |

→ 한 음성 세션 안에서는 언어를 바꾸지 못하지만, **새 음성 세션을 열 때의 직전 맥락**은 언어를 바꿀 수 있는 것으로 보인다. 확인한 사례가 005 하나뿐이라 실험이 더 필요하다(`../chatgpt-issue-log.md`의 실험 절차).

**v4 이후 추가 근거 (10-25)**: Chat 007·008·010·012에서 한국어 메타 질문에 음성으로 바로 한국어 답을 했다. 지침의 언어 규칙(한국어로 말하면 다음 답은 한국어)이 음성에서도 통한다 → "음성은 한 세션 안에서 언어를 못 바꾼다"는 v3 때 관찰은 지침 탓이 컸던 것으로 보인다.
